# Steiner's algorithm

Небольшая Java-программа для построения сети разряда на графе. Соединения учитывают расстояние между объектами и препятствия. Поиск общей сети выполняется динамическим программированием по подмножествам целей.

## Запуск

Нужен JDK 17 или новее.

```bash
javac -encoding UTF-8 -d out Djakstra.java
java -cp out org.example.Djakstra
```

В Windows можно запустить `run.bat`.

## Управление

- `1` — красный квадрат
- `2` — зелёный ромб
- `3` — голубой ромб
- `B` — шарик
- `K` — препятствие
- `C` — очистить поле
- левая кнопка мыши — передвинуть квадрат
- правая кнопка мыши — запустить поиск от ближайшего объекта

Логи сохраняются в `logs/log.txt`.
